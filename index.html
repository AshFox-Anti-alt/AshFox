Honest by design

Clear product boundaries. No inflated promises.

Trust comes from accurate descriptions, transparent limitations and practical safeguards.

Fingerprint configuration is not invisibility

AshFox changes selected browser-visible values for testing and profile management. It does not guarantee anonymity, evade every detector or reproduce a real device operating system. Websites can combine many signals, including behavior, network reputation and account history.

Local-first, with clear backup behavior

Profiles and browser sessions are managed locally. Encrypted backup bundles cover profile, proxy and extension configuration, not cookies, sessions or downloaded files. WebDAV storage is supplied by the user; AshFox does not currently provide hosted cloud storage.

Security is an ongoing practice

The supplied project documentation says the current desktop build has not been independently penetration-tested. Local proxy credentials are stored in configuration files protected by the Windows user account, not encrypted at rest. Use a protected Windows account and avoid shared devices for sensitive credentials.

Team Work is a local roster

The current Team Work page records a local roster and profile assignments. It does not provide remote invitations, cross-device synchronization or server-enforced role permissions. Those capabilities require a future backend implementation.

Online tools and data handling

Browser-local utilities process inputs in the visitor's tab. Live IP, DNS, OUI and certificate services are not connected in this preview. Before launch, publish a full privacy and cookie policy describing hosting logs, analytics (if any), retention and every external lookup provider.

Legal and responsible use

AshFox is presented for legitimate browser testing, QA, session organization and privacy configuration. Users remain responsible for complying with applicable law and the terms of services they access. Final jurisdiction-specific legal documents should be reviewed before public release.

Frequently asked questions

Know what you're getting.

Which browser engines does AshFox include?

The documented desktop build bundles Playwright Chromium, Firefox and WebKit. Some selectors for branded Chromium browsers try installed Chrome or Edge before falling back to the available Chromium engine. WebKit on Windows is not genuine Apple Safari.

Does AshFox guarantee that profiles cannot be detected?

No. Browser-visible settings are configurable, but they cannot guarantee anonymity or avoid detection. Real-world results depend on the browser, host operating system, network, proxy, website and other signals.

Does Cloud Sync include cookies and browser sessions?

No. Encrypted backups include profile metadata, proxy configuration and extension lists. Browser session folders, cookies and downloaded files are excluded. Cloud Sync uses a WebDAV server provided by the user.

Can I use extensions in Firefox or WebKit profiles?

The supplied build loads unpacked extensions for Chromium-based profiles only. Firefox and WebKit profiles ignore extension assignments.

Is the macOS, Android or iOS version available?

Not yet. These are future platform plans and are marked Coming Soon. The existing application reviewed for this website is a Windows desktop application.

Can this website read my device's real MAC address?

No. Web browsers do not expose the visitor's hardware MAC address to websites. The MAC utilities here validate and format values supplied by the visitor and can generate local example addresses. Manufacturer lookup requires a maintained OUI database service.
